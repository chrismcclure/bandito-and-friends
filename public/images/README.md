# Images

Drop image assets here. Files in `public/` are served at the site root (e.g. `/images/...`).

## Folders

| Folder | Contents |
|--------|----------|
| `title/` | Title screens, logos, and episode branding art |
| `characters/bandito/` | Bandito sprites and portraits |
| `characters/professor-spaghettio/` | Professor Spaghettio sprites and portraits |
| `characters/tortellini/` | Tortellini sprites and portraits |
| `characters/girl-frederick/` | Girl Frederick sprites and portraits |
| `backgrounds/` | Scene backgrounds and environment art |
| `props/` | Standalone objects used in scenes |

## Naming examples

```
title/bandito-and-friends.png

characters/bandito/bandito-idle.png
characters/bandito/bandito-walk-01.png
characters/bandito/bandito-walk-02.png

characters/professor-spaghettio/professor-idle.png

backgrounds/living-room.png

props/sock.png
```
